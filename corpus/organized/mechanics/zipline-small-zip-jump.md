- Ziplines Zipline Momentum Conservation, Zip Dash, Small Zip Jump, Zip Launch

- name: Small Zip Jump

- file: smallzipjump.mp4

- tech_type: Universal Tech

- difficulty: Advanced Easy

- character_dependent: No

- stamina: 0

- inputs: Dismount the Transit Line using crouch then jump within 0.14 seconds While dismounting using crouch from a [Transit Line](Ziplines.md), a small 0.14 second (or 9 ticks) window opens where you can execute a Small Zip Jump. Jumping during this window results in a regular jump from the Transit Line with the added benefit of no air drag from the crouch dismount.

This is very useful in conjunction with [Zipline Momentum Conservation](Zipline Momentum Conservation.md) for rollouts; the extra height unlocks new routes that would not be possible otherwise.
